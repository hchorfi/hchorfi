### 🧭 About Me

I'm an SRE/DevOps engineer at **YouCan**, a multi-tenant e-commerce SaaS platform, where I keep a fleet of servers running smoothly across multiple cloud environments. My day-to-day spans infrastructure reliability, network operations, and automation — basically, anything that pages me at 3am, I own it end-to-end. 🌙📟

### 🛠️ What I Work On

- **🚨 Incident response** — root-causing live production incidents under pressure, then hardening the system so the same failure mode can't recur
- **🌐 Network & DNS reliability** — designing resilient, self-healing architectures for high-traffic, attack-exposed services
- **🤖 Automation & Infrastructure as Code** — standardizing infrastructure at scale so provisioning and config drift stop being manual, error-prone work
- **☸️ Platform engineering** — building and operating the internal platforms that other teams rely on, with reliability and observability baked in from the start
- **🛡️ Security operations** — designing scalable, automated defenses against abuse and attack traffic
- **💰 Cost & operational efficiency** — turning raw operational data into dashboards and automated reporting that drive better decisions
- **📊 On-call ownership** — owning MTTR end-to-end and continuously feeding lessons learned back into tooling and process
